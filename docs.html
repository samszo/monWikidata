monWikidata

Application PHP pour explorer le dump JSON compressé de Wikidata. Chaque scan (~100 Go) est interruptible et repris automatiquement après timeout grâce à seekToPosition().

Installation

Prérequis

  • PHP 8.3+ (/opt/homebrew/bin/php sur macOS)
  • MariaDB — base wikidata créée manuellement
  • Composer
  • Dump wikidata-20240101-all.json.gz à la racine
composer install
cp config.example.php config.php   # host, port, dbname, user, pass

Les tables sont créées automatiquement au premier appel (getDb()). Les migrations ALTER TABLE … ADD COLUMN IF NOT EXISTS s'appliquent sur les bases existantes.

Architecture

Le mécanisme central est la boucle de reprise : au timeout, PHP sauvegarde la position byte du lecteur dans wikidata_scan_state. À la requête suivante, il appelle seekToPosition(saved_pos) sur le GzDumpReader pour reprendre exactement là où il s'est arrêté.

Onglet Géos

Extraction des coordonnées géographiques (P625) pour les entités référencées par P19 (lieu de naissance) déjà stockées dans wikidata_properties.

Le scan est résumable après timeout. Les coordonnées sont stockées dans wikidata_geos avec latitude, longitude, précision et globe (Terre par défaut).

-- Requête source
SELECT DISTINCT value_id FROM wikidata_properties WHERE property = 'P19';

Onglet Occupations

Extraction des entités référencées par P106 (occupation) avec leur hiérarchie subclass_of (valeurs P279 pipe-séparées).

-- Requête source
SELECT DISTINCT value_id FROM wikidata_properties WHERE property = 'P106';

Les occupations sont stockées dans wikidata_occupations(id, label, subclass_of). Le champ subclass_of contient les QID parents séparés par |.

Requête pour joindre les occupations avec leurs nœuds :

SELECT o.id, o.label, n.id, n.label
FROM wikidata_occupations o
LEFT JOIN wikidata_nodes n
  ON FIND_IN_SET(n.id, REPLACE(o.subclass_of, '|', ',')) > 0
WHERE o.id = 'Q10873124';
IN (CONCAT(...)) ne fonctionne pas : SQL traite le résultat comme une seule chaîne. Utilisez toujours FIND_IN_SET(n.id, REPLACE(..., '|', ',')) pour les champs pipe-séparés.

Arborescence des classes (SQL récursif)

Remonte la hiérarchie P279 depuis les classes directes (P31) d'une entité. La colonne path donne le chemin du général au particulier.

WITH RECURSIVE class_tree AS (
    -- Classes directes (P31) de l'entité
    SELECT c.id, c.label, 0 AS depth,
           CAST(CONCAT(c.id,' (',COALESCE(c.label,'?'),')') AS CHAR(10000)) AS path
    FROM wikidata_nodes n
    JOIN wikidata_p279_class c
      ON FIND_IN_SET(c.id, REPLACE(n.p31, '|', ',')) > 0
    WHERE n.id = 'Q28640'

    UNION ALL

    -- Superclasses via P279 (remonte la hiérarchie)
    SELECT g.dst_id, cls.label, ct.depth + 1,
           CONCAT(g.dst_id,' (',COALESCE(cls.label,'?'),') > ',ct.path)
    FROM class_tree ct
    JOIN wikidata_p279_graph g ON g.src_id = ct.id
    LEFT JOIN wikidata_p279_class cls ON cls.id = g.dst_id
    WHERE ct.depth < 20           -- limite anti-cycle
)
SELECT id, label, depth, path
FROM class_tree
ORDER BY path;
Le CAST(… AS CHAR(10000)) dans l'ancre est indispensable : sans lui MariaDB infère un type trop court et lève Error 1406 Data too long dès que le chemin devient profond.

Export GEXF

Le fichier GEXF produit est directement importable dans Gephi. Les nœuds portent un attribut p31 (valeurs pipe-séparées) lisible comme métadonnée de partition.

Gestion du timeout & reprise

Toutes les fonctions de scan partagent le même pattern de deadline :

// Calculé depuis REQUEST_TIME, pas depuis time() au lancement du scan,
// pour rester aligné avec set_time_limit(TIME_LIMIT).
$deadline = (int)$_SERVER['REQUEST_TIME'] + TIME_LIMIT - 5;

while (true) {
    if (time() >= $deadline) { $timedOut = true; break; }
    // ...scan...
}

if ($timedOut) {
    saveScanState($key, $reader->getPosition(), $total, $found);
} else {
    clearScanState($key);
}
Utiliser time() - $start >= TIME_LIMIT est incorrect : il mesure le temps écoulé depuis le début du scan, pas depuis le début de la requête HTTP. Si des opérations préalables ont consommé du temps, PHP tue le script avant que la condition ne soit vraie.
